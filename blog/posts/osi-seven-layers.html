The 7 Layers of OSI: Models, Functions, Protocols, and Devices

The Open Systems Interconnection model is a universal language for networking. Learn each layer, its PDU, key protocols, devices, and how encapsulation works.

OSI Layers Encapsulation Protocols Fundamentals

1. What is the OSI Model?

The OSI model (ISO/IEC 7498-1) is a conceptual 7-layer framework developed by ISO in 1984. It standardizes how different systems communicate by breaking network functions into distinct layers. Each layer provides services to the layer above and uses services from the layer below.

  • Purpose: Interoperability between different vendors and technologies.
  • Approach: Layered abstraction — troubleshoot by focusing on a specific layer.
  • Usage: Primarily a reference model; TCP/IP is what we actually use, but OSI is critical for understanding and troubleshooting.

4. Encapsulation and Decapsulation

As data goes down the OSI stack, each layer adds its own header (and sometimes trailer). As it goes up, each layer strips its corresponding header/trailer.

Sender encapsulates down; receiver decapsulates up, removing each header/trailer at the matching layer.

8. Key Takeaways

  • The OSI model has 7 layers: Application, Presentation, Session, Transport, Network, Data Link, Physical.
  • PDUs: Data (7-5), Segment/Datagram (4), Packet (3), Frame (2), Bits (1).
  • Addressing: Port numbers (L4), IP addresses (L3), MAC addresses (L2).
  • Encapsulation adds headers/trailers going down; decapsulation removes them going up.
  • Use OSI as a troubleshooting checklist — from bottom up (physical first) or top down depending on context.
  • TCP/IP is the real protocol suite, but OSI is the universal reference.
