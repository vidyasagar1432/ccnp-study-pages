VRF vs VRF Lite: Key Differences

Compare VRF Lite and MPLS L3VPN, when to use each, and how to verify.

VRF MPLS Segmentation Routing

Overview

VRF (Virtual Routing and Forwarding) creates multiple isolated routing tables on a single device. VRF Lite is the simplest form — no MPLS labels or MP-BGP required. MPLS L3VPN extends this across a service provider network using MP-BGP and label distribution.

Comparison

Aspect VRF Lite MPLS L3VPN
Scope Single site / small network Multi-site across provider
Control Plane Per-VRF IGP/static MP-BGP between PEs
Forwarding IP lookup per VRF MPLS label stack
Labels Not used Transport + VPN labels
Scale Smaller Large, many customers/sites

When to Use

  • VRF Lite: Guest WiFi, management VRF, lab segmentation, or single-router isolation.
  • MPLS L3VPN: Interconnect multiple sites over a provider MPLS network with overlapping address spaces.

Verification

show ip vrf
show ip route vrf CUSTOMER
show ip cef vrf CUSTOMER
show bgp vpnv4 unicast vrf CUSTOMER
