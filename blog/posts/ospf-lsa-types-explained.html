OSPF LSA Types Explained

A clear breakdown of OSPF LSA types 1-7, where they appear, and how to read them.

OSPF LSA Routing Troubleshooting

Overview

OSPF uses Link State Advertisements (LSAs) to describe the topology. Each LSA type serves a specific purpose and has a defined scope (area or domain). Understanding which LSA is flooded where is key to multi-area design and troubleshooting.

Common LSA Types

LSA Name Origin Scope Purpose
Type 1 Router LSA Every router Area Lists router links and their costs
Type 2 Network LSA DR on broadcast/NBMA Area Lists routers attached to the segment
Type 3 Summary LSA ABR Between areas Advertises inter-area prefixes
Type 4 ASBR-Summary LSA ABR Between areas Advertises reachability to ASBR
Type 5 AS-External LSA ASBR Domain (all non-stub areas) Advertises external routes
Type 7 NSSA External LSA ASBR in NSSA NSSA only Converted to Type 5 by ABR

Key Takeaways

  • Type 1/2 stay within an area.
  • Type 3/4 connect areas via ABR.
  • Type 5 carries external routes to the whole OSPF domain.
  • Type 7 is used in NSSA and translated to Type 5 at the ABR.
  • Stub areas block Type 5; NSSA blocks Type 5 but allows Type 7.

Verification

show ip ospf database
show ip ospf database router
show ip ospf database summary
show ip ospf database external
show ip ospf database nssa-external
