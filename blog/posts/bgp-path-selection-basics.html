BGP Path Selection Basics

Walk through the BGP best path algorithm in order with practical examples.

BGP Path Selection Routing

Overview

BGP chooses a single best path for each prefix using a well-defined algorithm. When multiple paths exist, attributes are compared in order until one remains.

BGP Best Path Selection Order

  1. Weight (Cisco proprietary, highest wins)
  2. Local Preference (highest wins, propagated within AS)
  3. Locally originated (network/aggregate/redistribute preferred over learned)
  4. AS-Path length (shortest wins)
  5. Origin code (IGP < EGP < Incomplete)
  6. MED (lowest wins, compared between same AS only by default)
  7. eBGP vs iBGP (eBGP preferred over iBGP)
  8. Lowest IGP metric to BGP next hop
  9. Oldest eBGP path (or multipath rules)
  10. Lowest Router ID (tie-breaker)
  11. Minimum cluster list length / lowest neighbor address

Quick Tips

  • Use weight for quick, per-router control.
  • Use local-preference to influence outbound traffic for the whole AS.
  • Use AS-path prepend or MED to influence inbound traffic.
  • Remember MED comparison rules vary with bgp always-compare-med and AS-path.
